# Prototipo de registro de solicitudes de soporte técnico

Proyecto grupal de la asignatura PFU-111 – Programación Fundamental (Semana 12).

## ¿Qué hace el programa?

Es un programa en Python que funciona en consola con un menú. Sirve para registrar solicitudes de soporte técnico de estudiantes. Antes de guardar una solicitud, revisa que los datos estén correctos y muestra un mensaje claro si hay algún error.

## Datos que se registran

- Nombre del solicitante
- Código de estudiante (8 dígitos)
- Tipo de solicitud (equipo, software o conectividad)
- Descripción del problema
- Prioridad (bajo, medio o alto)

## Menú

1. Registrar solicitud
2. Consultar solicitud
3. Limpiar datos
4. Salir
